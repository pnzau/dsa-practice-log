# DSA practice log

Each challenge lives in one TypeScript file under `src/dsa`. Keep the solution and its `node:test` tests together so a challenge can be opened, edited, and run in one place.

## Commands

Install dependencies:

```sh
npm install
```

Run one challenge by filename stem:

```sh
npm run dsa -- rate_limiter
```

Run every challenge:

```sh
npm run dsa:all
```

Check types:

```sh
npm run typecheck
```
